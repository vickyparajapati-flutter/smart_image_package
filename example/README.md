# SmartImageX example

A small app demonstrating the headline features of
[`smart_image_x`](../README.md):

- **Basics** — the simplest usage, BlurHash progressive loading, and
  auto-detected inline SVG.
- **Shapes & States** — circle avatars, rounded corners, greyscale, and the
  error → fallback-icon chain.
- **Gallery & Zoom** — a tappable grid that opens a swipeable, zoomable,
  hero-animated `SmartImageGallery`.
- **Cache** — live `cacheStats()`, preloading, and cache clearing.

## Run

```bash
cd example
flutter pub get
flutter run
```
